A personal Android travel journal

Privacy policy

Where to next? is a personal Android travel journal developed by Stephanos. This policy explains how the Android app, personal cloud, encrypted backup tool, and this information website handle data.

Last updated: 23 September 2026.

Journal data on your phone

The app stores visited countries and attractions, custom places, descriptions, visit dates, photo metadata and ordering, traveller progress, achievements, and settings locally. After you select a photo, the app makes a compressed display copy in Android app-private storage. It does not upload the full-resolution original by default.

Photos and location permissions

The Android system Photo Picker lets you choose images without broad photo-library access. A selected image may come from Google Photos or another cloud-media provider, which may download it during selection. Once the display copy is saved, the app uses that local copy for offline viewing.

When available and permitted, device location can set the initial map position. Location is optional and the map has a fallback. The app saves the avatar's map position, which may initially reflect your device location; that saved position is included in journal sync. The app does not continuously track your device's location in the background.

Personal cloud sync

If you sign in to the optional personal cloud, the Android app uploads and downloads journal state and compressed display photos through an authenticated HTTPS service on netcup Webhosting. The journal includes photo placement, descriptions, visits, progress, settings, and the saved map position. The service also stores account and device records, media hashes, revision history, and technical information needed for authentication and sync. Android stores its device credential in protected storage. This personal cloud uses its own password; the Android app does not request Google Drive authorization.

Google Drive recovery backup

A separate backup tool run by the operator on a computer can export the personal cloud's database and private media files, encrypt the archive locally, and upload only the encrypted archive to Google Drive. The archive contains the journal, compressed display photos, account password hash, and device records. Google Drive receives the encrypted archive and its file name, size, and upload metadata; the decryption identity is kept outside Google Drive and the server.

The backup tool uses the drive.file Google permission to create, read, and manage only the Drive files and folders it creates. Google handles authorization; the backup tool stores an OAuth token on the operator's computer and never asks for the Google account password. Google user data accessed through this connection is used only to store and verify recovery archives. It is not sold, used for advertising, or used to train AI models. This use follows the Google API Services User Data Policy, including its Limited Use requirements.

Other services

The photo provider may receive a request when you first select a cloud-hosted image. Optional online map detail and attraction images send ordinary network requests, including your IP address and requested resources, to map providers and Wikimedia image servers. These requests can reveal the map areas or attraction images being requested.

This website uses GitHub Pages hosting. GitHub processes visitor network information under the GitHub Privacy Statement. The website adds no analytics, cookies, or tracking scripts. The Android app has no advertising or analytics integration.

Retention, deletion, and your choices

You can edit journal entries and remove photos in the app. Clearing Android app storage or uninstalling removes local journal data, display copies, and the stored device credential; Android device backup settings may affect retained device backups. Synced revisions and media remain on the personal cloud for recovery until the operator deletes them. Disconnecting revokes that phone's cloud credential and stops its sync, but does not delete the journal or server photos. The operator can revoke other devices through the app.

Encrypted Google Drive recovery archives remain until the operator deletes them under the backup retention plan. Revoking the backup tool's Google access stops future access but does not delete existing archives. Contact the developer for help deleting personal cloud data or backup archives.

Security and changes

Personal cloud requests use HTTPS, local display photos use Android app-private storage, and off-host server backups are encrypted before upload to Google Drive. A complete clean-phone restore and independent backup restore are still being verified. This policy will be updated when data practices change.
